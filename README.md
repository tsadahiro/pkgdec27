The goal of pkgdec27 is to generate, manipulate, and plot the random sorting networks of type B.

## Installation

You can install the development version of pkgdec27 from [GitHub](https://github.com/) with:

``` r
# install.packages("pak")
pak::pak("tsadahiro/pkgdec27")
```

## Example

This is a basic example which shows you how to solve a common problem:

``` r
library(pkgdec27)
## basic example code
```
